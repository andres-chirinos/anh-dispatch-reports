# ANH dispatch reports

This repository contains hydrocarbon dispatch reports from the National Hydrocarbons Agency (ANH).

This information is no longer presented in this format, and this workflow has been deprecated. The reporting period is from June 15, 2025, to November 12, 2025.

Information Dashboard: https://www.andreschirinos.com/anh-dispatch-reports/

Open Dataset: https://www.kaggle.com/datasets/sociest/anh-dispatch-report/
